# インストール方法

「Takos を使い始めること」と「Takos にアプリを追加すること」は別の操作です。

## Takos を使い始める

### 運営者が提供する Takos

運営者から案内された URL を開き、サインインして Workspace を作成します。サインアップの可否、料金、保存期間は運営者ごとに異なります。

[スタートガイド](/get-started/) に進んでください。

### セルフホスト

自分の Cloudflare アカウントへ Takos を配置します。アカウント、ドメイン、課金、バックアップ、secret は自分で運用します。

[セルフホスト](/deploy/) に進んでください。

## Workspace にアプリを追加する

Apps から Git リポジトリを指定します。

```text
Git URL + tag または commit + module path
  ↓
作成・変更されるリソースを確認
  ↓
plan を承認
  ↓
デプロイ完了
  ↓
Apps に起動 URL と状態を表示
```

画面では「Git URL から追加」「Install from Git」などと表示される場合があります。

アプリの候補一覧は、Git リポジトリを見つけやすくするためのものです。中央の一覧に登録されていないリポジトリも、互換性があれば URL を直接入力できます。一覧にあることは、安全性や品質の保証ではありません。

本番利用では、内容が変化する `main`、`latest`、`HEAD` を避け、tag または commit に固定します。

詳しい手順は [はじめてのアプリ](/get-started/your-first-app) を参照してください。

## どれを選ぶか

| やりたいこと | 方法 |
| --- | --- |
| すぐに Takos を使う | 運営者が提供する Takos |
| データとクラウド契約を自分で管理する | セルフホスト |
| 文書、シェル、Git などの機能を足す | Apps からアプリを追加 |
| 既存の MCP サーバーを使う | Connections から接続 |
