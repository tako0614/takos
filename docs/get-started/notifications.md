# 通知

Takos の通知は、エージェントの作業が終わったことや、Workspace で確認が必要な出来事を知らせます。

## エージェントの完了通知

エージェントの実行が完了または失敗すると、依頼した利用者へ通知が作成されます。通知を開くと、対象の会話へ戻れます。

同じ完了イベントが再送されても、同じ通知が重複して増えないように処理されます。

## 通知方法

Takos の通知設定には、次の方法があります。

| 方法 | 現在の用途 |
| --- | --- |
| アプリ内 | エージェント実行の完了・失敗、Workspace 招待 |
| モバイル push | エージェント実行の完了と失敗 |

Takos のモバイル push は、現時点では `run.completed` と `run.failed` だけを対象にします。Yurucommu の投稿やメッセージ、Yurumeet の予定などは、それぞれのアプリが管理する通知です。

push を実際に受け取れるかは、利用している Takos の運営設定と、端末側の許可にも依存します。Takos は現在、メール通知を提供していません。

## 通知が届かないとき

1. 対象の実行を依頼したアカウントでサインインしているか確認する
2. エージェントの実行状態が完了または失敗になっているか確認する
3. Takos の通知設定と、端末の通知許可を確認する
4. 会話を直接開き、結果が記録されているか確認する
5. 運営者は通知キューと push 配送設定を確認する

通知は実行結果そのものではありません。通知が届かない場合も、Chat に記録された実行状態を正しい結果として確認してください。
